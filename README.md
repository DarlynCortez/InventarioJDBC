## Entidad elegida

Producto 
se registra el inventario de productos de una tienda, con los siguientes atributos:
- id: identificador único
- nombre: nombre del producto
- cantidad: cantidad disponible en inventario

## Tecnologías utilizadas

- Java 21
- Maven
- H2 Database (embebida)
- JDBC


## Cómo ejecutar

1. Clonar el repositorio
2. Abrir el proyecto en IntelliJ IDEA
3. Recargar las dependencias de Maven (Load Maven Changes)
4. Ejecutar Main.java

Al ejecutar, se crea automáticamente el archivo inventario.mv.db en la raíz del proyecto con la tabla producto.
